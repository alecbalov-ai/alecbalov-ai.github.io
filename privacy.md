# Privacy Policy - Fabrica Video / The Mystery Vault

Last updated: November 5, 2026

Fabrica Video is a private tool used only by the owner of the YouTube channel The Mystery Vault to upload videos to that channel.

## What data the app accesses
The app uses the YouTube Data API with the owner's permission (scopes youtube.upload and youtube.readonly) only to upload videos and read the channel's own upload status.

## What we store
The access token is stored only on the owner's own computer. No data is sold, shared or transferred to third parties. No data from other users is collected.

## Google API Services
Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

## Revoking access
Access can be revoked at any time at https://myaccount.google.com/permissions
